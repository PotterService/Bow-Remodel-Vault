# 🏠 Bow Remodel Vault

> **Plan. Build. Track. Finish.**

Bow Remodel Vault is a free, local-first home remodeling and renovation manager built to help homeowners, DIY enthusiasts, landlords, contractors, and property managers organize every part of a renovation project from start to finish.

🌐 **Website:** https://remodel.potterservice.com

---

## ❤️ Why Bow Remodel Vault?

Most remodeling software is expensive, cloud-based, or requires creating an account.

Bow Remodel Vault was built with a different philosophy.

- Your data belongs to you.
- No subscriptions.
- No account required.
- Local-first.
- Easy to use.
- Fast.
- Free.
- Built for homeowners, DIY enthusiasts, landlords, and contractors.

Whether you're repainting a bedroom or completely renovating a house, Bow Remodel Vault helps keep everything organized in one place.
